# Operation — <title>

> Template for a reusable procedure that is invoked whenever the situation calls for
> it, rather than once at a fixed point in the project.

## When to run

The trigger. Be specific: "before any commit that changes analysis code", not
"periodically".

## Inputs

What the operation needs to be pointed at (a diff, a file, a result, a claim).

## Procedure

A checklist that can be worked through in order.

## What counts as done

The condition under which the operation has been carried out, and what is recorded
as evidence that it was.

## Escalation

What to do when the operation finds something: fix it silently, fix it and log it,
stop and ask. Say which.
